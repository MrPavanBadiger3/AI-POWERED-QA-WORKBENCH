# Backup evidence (demo fallback)

After a **real** end-to-end run on your machine, click *Documentation → Export all artifacts*, then copy
screenshots of the dashboard, a failing test's evidence, the pytest HTML report, and the RTM into this folder.

During the demo, if the internet or Groq is down, show these files and say clearly:
**"This is recorded evidence from an earlier live run (date/time), not a live execution."**
Never present backup evidence as live.
