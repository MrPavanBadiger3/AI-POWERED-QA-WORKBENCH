# Submission artifacts

| Folder | Filled by |
|---|---|
| `requirements/` | `sample_requirements.md` (human-authored). Approved requirements are written here by **Documentation → Export all artifacts**. |
| `test_scenarios/` | Exported approved AI analyses (after you run the workflow with a real key). |
| `test_cases/` | Exported approved test cases (JSON + CSV). |
| `defect_reports/` | Exported approved defect reports. |
| `execution_reports/` | Exported pytest-HTML and summary reports of completed executions. |
| `backup_evidence/` | Put screenshots/reports from your own real run here for the demo fallback (see its README). |

**Nothing in these folders was pre-generated by the AI or by a test run.** The project was prepared in an
environment with no access to Groq or SauceDemo, so AI outputs and execution evidence must be produced on your
machine (≈10 min, see `docs/DEMO_GUIDE.md` → "Before the demo"). Fabricated samples would violate the project's
own "no fake implementation" rule.
